# ASMA Lines v8.3 — обновление герба и сценариев заявок

Дата: 30.10.2026

## 1. Герб
- Светлая версия герба восстановлена на основе исходной геометрии `assets/asma-crest-dark.svg`, а не ручной перекраской повреждённой светлой версии.
- Сохранена форма колеса повозки с отдельными спицами и центральной втулкой: в светлой версии использованы те же контуры, что и в исходной тёмной версии.
- Для светлой темы применён фирменный бордовый `#7A1F33`; тёмная версия не изменялась.

## 2. Разделение пользовательских сценариев
Теперь три сценария имеют разные цели:

1. **Предварительный расчёт** (`calculator`) — пользователь оценивает бюджет по маршруту и грузу. Контактные данные не нужны, расчёт сам по себе не является заказом.
2. **Заказать перевозку** (`request`) — одна конкретная перевозка: маршрут, дата, груз, параметры, контакты. Если пользователь пришёл из калькулятора, параметры переносятся через `sessionStorage`; повторный ввод не требуется. В черновик добавлен объём груза.
3. **B2B-сотрудничество** (`contacts`) — запрос для регулярных поставок/долгосрочной работы. Форма спрашивает направления, частоту и ориентировочные объёмы; она больше не выглядит как вторая заявка на тот же разовый рейс.
4. **Массовая загрузка** (`bulk-request`) остаётся отдельным путём для списка нескольких рейсов из Excel/CSV.

В блоке переходов на страницах расчёта и заявок явно объяснено различие между оценкой, заказом одного рейса и импортом нескольких рейсов.

## 3. Мобильная адаптация
- Добавлены ограничения `min-width: 0` для сеток и дочерних элементов, чтобы длинные тексты не расширяли viewport.
- На узких экранах блок герба и текст страницы «О компании» располагаются вертикально.
- Для изображения герба задано ограничение ширины и автоматическая высота.
- Сетка страницы контактов также сворачивается в одну колонку.

## 4. Проверки
Успешно:

## 5. Публикация
Изменения внесены только в локальную копию проекта. Cloudflare Worker/Pages и удалённая D1 не изменялись. Перед публикацией следует открыть сайт в реальном мобильном браузере (ширина 360–430 px), проверить обе темы, отправку B2B-формы и перенос параметров из калькулятора в заявку.
