# Дизайн-система ASMA Lines

Единый стиль сайта: тёплая бумага + бордовый акцент, моноширинные подписи, прямые углы.

| Файл | Для чего |
|---|---|
| `assets/home.css` | Общая оболочка публичных страниц: шапка, подвал, секции, формы и плавающая кнопка связи |
| `assets/interior-polish.css` | Дополнительная дизайн-система для калькулятора, FAQ, партнёров и политики конфиденциальности: сетки, состояния, темы и мобильные раскладки |
| `assets/calculator.css` | Калькулятор: функциональные стили + новое оформление (подключается после `home.css`) |
| `assets/order-modal.css` | Окно «Быстрый заказ рейса» |
| `assets/crm-next.css` | Диспетчерская (Mini App): та же палитра через переменные |
| `order-doc.html`, `proposal.html` | Служебные / печатные документы: адаптивная оболочка и стили печатной версии в inline-`<style>` |

## Токены

- Палитра и итоговые значения обеих тем — в таблице ниже (источник истины: `home.css`; `system.css` лишь даёт псевдонимы `--primary`, `--ring`, `--link`).
- Шрифты: Inter (текст), JetBrains Mono (подписи, цифры, кикеры)
- Скругление 2–4 px; тени почти не используются

Тема переключается атрибутом `data-theme` на `<html>` (`theme-init.js`). `interior-polish.css` подключается после основных стилей страниц и использует те же переменные, не заводя отдельную палитру. В коммерческом предложении бумажная область остаётся белой для печати, а фон и панель действий учитывают выбранную тему. Переменные: `--bg --band --card --ink --mute --line --acc --kick`.

## Правила

- Любая правка ассета требует смены `?v=`: `node _tools/sync-asset-versions.mjs --fix`.
- Новые страницы копируйте с `faq.html`: шапка и подвал там эталонные.
- Не добавлять выдуманные цифры и отзывы: только подтверждённые данные.


## Токены цвета — фактические значения (сверено 27.10.2026)

Единственный источник истины — переменные темы в `assets/home.css`; слой `assets/system.css` только задаёт семантические алиасы
(`--primary`, `--ring`, `--link` и др.) и **не переопределяет** основной бордовый.

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--bg` | #faf7f1 | #151114 | фон страницы |
| `--band` | #f1ece5 | #20191d | полосы, вторичные поверхности |
| `--card` | #fffdf9 | #21191e | карточки |
| `--ink` | #231a1d | #f5eeef | основной текст |
| `--mute` | #71676b | #b5a8ad | вторичный текст |
| `--line` | #e2d9d3 | #3c3036 | границы |
| `--acc` (= `--primary`) | #7a1f33 | #a54860 | кнопки, акцент |
| `--kick` | #8c3047 | #d59aa8 | подписи-кикеры |
| `--ring`, `--link` | = `--acc` | = `--kick` | фокус и ссылки |

Итоговый тёмный `--acc` — #a54860 (проверено в браузере); конкурирующих переопределений `--primary` больше нет.

## Изображения для двух тем

Парные файлы переключаются классами `img-light` / `img-dark` и `data-theme` (правила в `system.css`).
У обоих `<img>` стоит `loading="lazy"`: скрытый вариант не загружается. Для главной `theme-init.js` добавляет preload
иллюстрации выбранной темы. Подключённые пары: `asma-hero-visual(.svg|-dark.svg)` — главная; `asma-flat-truck(.svg|-dark.svg)` — калькулятор;
`brand/asma-mark-light.svg` / `asma-mark-dark.svg` — шапка.
Сцены `img/*-road|fleet|city|auto` и `img/light/*` на страницах не используются (см. AUDIT-FIX-REPORT.md).
